First fixes from testing on real hardware.

## Fixed
- OpenRGB server segfaulted in a crash loop. The unit blocked `AF_NETLINK`, so libusb could not
  initialise and OpenRGB used a dead context. Netlink is allowed now, and a start limit stops the
  service retrying forever
- `pl` reaches the third RAPL constraint. All three read as writable on the x15 R2, but the verb
  only accepted 1 or 2, so `peak_power` was unreachable
- Install hints say `sudo` for the system unit
- `.gitignore` no longer ignores makepkg build output

## Verified on an x15 R2
- `alienwarectl status` returns every field with no warnings
- Fan, temperature, profile, turbo, RAPL, CPU clock and GPU draw all read correctly
- Power limits are not firmware locked on this machine
