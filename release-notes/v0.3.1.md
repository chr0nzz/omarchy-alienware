Wide keys light across their whole width.

## Fixed
- Backspace, caps lock, left shift and the super key lit at half their width. Each carries two
  leds and the map recorded only one of them. The second led of each sits at an index the map
  listed as a hole, and every neighbouring index really is a hole, so nothing looked wrong

| key | indices |
| --- | --- |
| backspace | 34 + 35 |
| caps | 60 + 61 |
| lshift | 80 + 81 |
| lsuper | 102 + 103 |

## Changed
- `kbKey` carries an `indices` array and `cmdKbdSetMap` emits every led for a key, so one paint
  covers the whole key through every write path, including the theme colour, the mute overlay and
  the restore that runs on resume
- The key map is complete at 88 leds across 84 keys. The remaining 48 indices are matrix holes.
  There is no addressable zone for the mute indicators and the caps lock dot is not in the matrix
  either, both are firmware driven
- The readme documents the key map, the `kbd identify` verb, the advisory flock, and the fact that
  the PKGBUILD builds a tag rather than the working tree
- Uninstall is documented, including blanking the lighting before the binary goes, since the
  controllers hold their last frame
