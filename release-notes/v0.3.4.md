Plugin settings are read again after the Omarchy 4.0.3 update.

## Fixed
- Every setting in `shell.json` was ignored and the built in defaults were used instead. Omarchy
  4.0.3 removed `shellConfig` from the scoped object plugins receive as `shell`, replacing it with
  `barConfig`, which holds the bar section rather than the whole file. The lookup now reads
  `barConfig` and accepts either shape, so it works on 4.0.3 and on older versions
- There was no symptom to notice: poll interval, hot temperature, display mode and theme sync all
  have defaults, so the plugin looked healthy while quietly ignoring what was configured
