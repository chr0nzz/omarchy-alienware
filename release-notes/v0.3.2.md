The 0.3 releases now actually publish.

## Why

Both 0.3.0 and 0.3.1 were tagged but never released. The release workflow runs the
full suite before publishing, and it failed twice for two unrelated reasons, so no
binaries were ever attached and no release appeared.

`TestCurveDrivesBoostAndFailsSafeOnStop` polled until the CPU fan boost reached 200
and then immediately asserted on the GPU fan, but the curve loop writes the two in
sequence. On a loaded runner the test could observe the first write and not the
second, and read an absent file as an empty string. It synchronised on one signal and
asserted on another. It now waits for both before asserting.

The test runner was also invoked as `node --test tests/`. Passing a directory needs a
newer node than the 22 that CI pins, so it resolved the path as a module and died with
MODULE_NOT_FOUND. It is now a shell expanded glob, which every version accepts.

## Changed

- `TestCurveDrivesBoostAndFailsSafeOnStop` waits for both fan writes, no longer flaky
- `npm test` runs `node --test tests/*.test.js`, which works on node 22 and later and
  still keeps the clone that makepkg leaves in `packaging/` out of the run
- Contains everything from 0.3.0 and 0.3.1, which have tags but no published release
