First release.

## Fans
- Live RPM and temperature for both fans, read from the `alienware_wmi` hwmon
- Drag point boost curve, run as a userspace loop with hysteresis
- Boost is additive, so a curve raises the fans above the firmware curve and never below it
- Fans reset to firmware control on stop, on crash, and on kill

## Power
- Thermal profile switching across all six `platform_profile` values
- CPU turbo toggle, CPU clock, GPU power draw
- PL1 and PL2 sliders, read only when firmware locks them
- GPU power limit shown read only, it follows the thermal profile

## Lighting
- Per zone RGB through the OpenRGB SDK server, no root
- First run wizard to identify and name the zones, since the x15 R2 reports 20 unnamed slots
- Six hardware effects

## Helper
- `alienwarectl`, one static Go binary, root daemon plus user CLI
- D-Bus system bus with polkit on every write
- Stopping a curve needs no authorization, so a polkit fault can never keep the fans pinned

## Known limits
- Battery charge limit and GPU MUX have no interface on this model
- The GPU power limit cannot be set, only read
