0-15 = ESC F1-F12 HOME END DEL (top row)
16-31 = ` 1 2 3 4 5 6 7 8 9 0 - plus mic mute, vol mute, vol up, vol down
        note: = and Backspace are NOT in this block, media keys interleave
32-47 = "=", RETURN, TAB, Q, W, E, R, T, Y in order, remaining indices unconfirmed

CONCLUSION: the wire order is the keyboard matrix, not the visual layout.
Return appears between "=" and TAB, and Backspace has not appeared in 0-47.
A per key map cannot be inferred from the layout and must be discovered per
machine. Build the mapping as a wizard in the panel instead: light one index,
have the user press or click the matching key, record the pairing.

Proven so far:
- APIv5 over /dev/hidraw1 works, feature id 0xcc, 64 byte reports
- single key addressing works, index 0 is ESC
- "all" lights every key, range 0-135 accepted
- the kernel keyboard driver stays bound, typing is unaffected
